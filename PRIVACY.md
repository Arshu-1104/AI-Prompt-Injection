# Privacy Policy for PromptGuard Chrome Extension

Last updated: July 2026

## What data we collect
PromptGuard reads text from input fields on AI chat 
interfaces (ChatGPT, Claude, etc.) to analyze for 
prompt injection patterns.

## How we use data
Text from input fields is sent ONLY to your configured 
API endpoint. No data is sent to third parties.

## Data storage
Your API endpoint URL and API key are stored locally 
on your device using Chrome's storage API.

## Data sharing
We do not sell, trade, or transfer your data to 
outside parties.
