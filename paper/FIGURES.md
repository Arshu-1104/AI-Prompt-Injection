# Figures for the revised paper

All figures are single-column (3.5 in / 8.9 cm wide) unless noted. Use black, white and one grey
(#BFBFBF); IEEE prints in greyscale. Font: the same sans-serif everywhere, 7-8 pt at final size.
Export from draw.io as PDF (File > Export as > PDF, "Crop" ticked) and save as `paper/fig1_architecture.pdf`.

## Fig. 1: PromptGuard components and data flow (draw yourself in draw.io)

Left to right, three columns. Keep it plain: boxes and arrows, no icons or logos (no ChatGPT,
Claude or Gemini logos; write the site names as text).

1. **User's browser** (dashed outer box)
   - Box: "Chat website prompt box (chatgpt.com, claude.ai, gemini.google.com)"
   - Box inside it, small: "PromptGuard extension: content script + badge"
   - Small grey note under it: "pasted email / web page / document" with an arrow into the prompt box
     (this is the indirect-injection path of the threat model).
2. **PromptGuard API** (solid box), arrow from the extension labelled
   "text after 500 ms pause (HTTPS, API key)"; return arrow labelled
   "label, confidence, risk score, patterns, top words".
   Inside the API box, stacked:
   - "clean_text (decodes Base64/ROT13)"
   - "Classical: TF-IDF + logistic regression"
   - "bert: DistilBERT" and "guard: ModernBERT" side by side, both marked "optional"
   - "Rule floor" and "escalation: SUSPICIOUS & conf < 0.65 -> guard" as a small arrow
     from Classical to guard (reviewers noted the old figure did not show escalation)
   - "Patterns (explanation only)"
3. **Storage and dashboard** (right): cylinder "Database: hash of text, label, scores (no text by default)";
   box "Dashboard: API keys, logs, playground". Arrow API -> database.

Labels in the figure must be SAFE / SUSPICIOUS / MALICIOUS (with "(Safe / Review / Danger in the UI)"
once, near the badge). Do not use any other label names.

## Fig. 3 (`fig:explain`): Explaining a flag with no matching pattern (screenshot, captured by script)

A large, readable crop of the dashboard Playground (1600 px wide or more) for a prompt the classical
model flags without any pattern, showing:
- the label badge and the risk score,
- the risk-score breakdown line "= base 85 (label) + 0.0 (patterns) + x.x (confidence)",
- the highlighted words ("Words that contributed most to this label").
Annotate in draw.io with three thin callout arrows: (a) label, (b) score breakdown, (c) highlighted words.
The script that captures it writes `paper/fig2_explanation.png`; the prompt and its output are recorded
in `artifacts/fig2_example.json` so the caption's numbers are traceable.
